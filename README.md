# OpenCV Image Processing Lab3 (Image manipulation using OpenCV library)

This repository contains Python scripts demonstrating fundamental image processing techniques using the OpenCV library (`cv2`) and NumPy.

## What I Learned

### 1. Basic Image I/O and Display

* **Reading Images**: Using `cv2.imread()` to load images in default (BGR) and grayscale (`cv2.IMREAD_GRAYSCALE`) formats.
* **Displaying Images**: Using `cv2.imshow()` to render images in a window.
* **Window Management**: Using `cv2.waitKey()` to pause execution until user interaction, and `cv2.destroyAllWindows()` to properly close the GUI windows and prevent freezing.
* **Saving Images**: Writing array data back to disk as image files using `cv2.imwrite()`.

### 2. Color Space Conversions

* Converting from standard BGR to Grayscale using `cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)`.
* Exploring different color spaces like YUV (`cv2.COLOR_BGR2YUV`) and isolating them into their individual channels (Y: brightness, U: blue projection, V: red projection) using NumPy array slicing (`img[:, :, channel_index]`).

### 3. Geometric Transformations

* **Scaling**: Enlarging or shrinking an image using `cv2.resize()` with specific interpolation techniques like `cv2.INTER_CUBIC`.
* **Rotation**: Rotating an image around its center using a transformation matrix generated by `cv2.getRotationMatrix2D()` and applied via `cv2.warpAffine()`.
* **Shearing**: Applying a custom 2x3 affine transformation matrix (e.g., `[[1, shear_x, 0], [0, 1, 0]]`) using `cv2.warpAffine()` to shift pixels along the X or Y axis.

### 4. Intensity Transformations (Point Processing)

* **Image Negatives**: Inverting image colors by subtracting the pixel values from the maximum value (e.g., `255 - img`).
* **Log Transformations**: Expanding dark pixels and compressing bright pixels using the formula `c * log(1 + r)`. This requires converting arrays to floats to prevent calculation overflow.
* **Power-Law (Gamma) Corrections**: Adjusting overall image contrast using the formula `c * r^gamma`.
  * *Gamma > 1*: Expands bright regions (good for washed-out images).
  * *Gamma < 1*: Expands dark regions (good for dark images).
  * Implemented highly efficiently using OpenCV's Look-Up Table function (`cv2.LUT()`).

## Troubleshooting Note: Freezing Windows

When running OpenCV scripts in certain IDEs or Jupyter Notebooks, the image windows may freeze. To fix this, instead of clicking the red "X", ensure you press a key on the keyboard, and always follow `cv2.destroyAllWindows()` with a tiny delay like `cv2.waitKey(1)` to force the GUI event loop to update.
